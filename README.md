# Kids Quiz App

A colorful, beginner-friendly quiz game designed for children around age five. Built with HTML, CSS, and vanilla JavaScript.

## Features
- Choose Numbers, Animals, Colors, Letters, or All Topics
- Five randomized questions per round
- Four answer choices per question
- Friendly feedback and star scoring
- Final score screen and replay option
- Responsive layout for phones, tablets, and computers

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

No installation or build tools are required.

## Publish with GitHub Pages
1. Create a GitHub repository named `kids-quiz-app`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment settings, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish your site and open the URL shown there.

## Project files
- `index.html` — page structure
- `style.css` — colors, layout, and responsive design
- `script.js` — questions, scoring, and quiz behavior

## Note
This is an educational practice project. Adult guidance is recommended when young children use online services.
